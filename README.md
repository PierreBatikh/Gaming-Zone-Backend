# Gaming Survey — Django Web App

A simple Django web application built as my first project to put my Django and Python knowledge into practice.

The app is centered around a form that collects information from people about their gaming habits, preferences, and experiences. The goal was to build something functional while getting hands-on experience with Django's core concepts and the flow of handling user-submitted data.

## About the Project

This project was created primarily as a learning experience. It gave me the opportunity to practice working with Django and understand how the different parts of a web application fit together.

Some of the things I worked with include:

* Django project and app structure
* Forms and handling user input
* Processing submitted data
* Django views and URLs
* Templates and connecting the frontend to the backend
* Database interaction
* Running a Django application locally

The project is intentionally straightforward, but it represents an important step in learning how to build web applications with Django.

## Getting Started
Requirements
Python 3.x
Django
## Installation

* Clone the repository and move into the project directory:

```
git clone REPOSITORY_URL
cd PROJECT_DIRECTORY
```


* Create and activate a virtual environment:
```
python -m venv venv
```

On Windows:
```
venv\Scripts\activate
```

On macOS/Linux:
```
source venv/bin/activate
```

* Install the dependencies:
```
pip install -r requirements.txt
```

* Apply the migrations:

```
python manage.py makemigrations
python manage.py migrate
```

* Start the development server:
```
python manage.py runserver
```

* Then open the local address shown in the terminal.
